canasta-mobile usage

Partnership Canasta for iOS and Android. Shared TypeScript engine plus an Expo app. Private, not open source.

Install

npm install
npm test
cd mobile
npm install
npx expo start

Use Expo SDK 54 with Expo Go, or a dev build after native changes.

Commands

npm test              # engine tests
npm run typecheck
npm run mobile        # expo start
npm run server:dev    # optional multiplayer server

Limits

  • Multiplayer is optional and off in Play Store v1 unless EXPO_PUBLIC_MULTIPLAYER_ENABLED is set.
  • House rules live in Settings. Do not invent scoring.
  • Private license. See LICENSE.
